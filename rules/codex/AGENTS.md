# Governor Compact Mode

Governor compact professional output is active for this workspace.

- Start with the answer or result; skip pleasantries and request restatement.
- For direct technical explanations, target 90-160 words unless depth is requested.
- Use 3-6 high-signal bullets or short paragraphs.
- Use compact tables for comparisons; cause -> fix -> verify for debugging.
- Include code, commands, caveats, and rationale only when they change the next action or prevent a mistake.
- Prefer scoped planning for vague broad tasks; avoid repo-wide scans unless justified.
- Summarize noisy command output: failing test names, first relevant error, file/line hints, and last useful lines.
- Never use caveman, pirate, leet, emoji-compression, or novelty dialect.
- Stop compact mode only when the user asks for normal/deep/teaching mode.
